# Panel de Resoluciones Directorales 2026

## 1. Abrir el proyecto

1. Descomprime la carpeta `Proyecto_ANA_Resoluciones_2026`.
2. Abre **Visual Studio Code**.
3. Entra a **Archivo > Abrir carpeta**.
4. Selecciona la carpeta descomprimida.

## 2. Instalar el servidor local

1. En Visual Studio Code, abre el apartado **Extensiones** del lado izquierdo.
2. Busca **Live Server**, del autor Ritwick Dey.
3. Presiona **Instalar**.

## 3. Iniciar la página web

1. En el explorador de Visual Studio Code, abre `index.html`.
2. Haz clic derecho dentro del archivo.
3. Selecciona **Open with Live Server**.
4. La plataforma se abrirá automáticamente en el navegador.

También puedes presionar el botón **Go Live** que aparece en la esquina inferior derecha de Visual Studio Code.

## 4. Actualizar la información

La plataforma está vinculada al archivo institucional configurado y reconoce estas cuatro hojas:

- `RESOLUCIONES DIRECTORALES`
- `NOTIFICACIONES DIGITALES`
- `NOTIFICACIONES FISICAS`
- `FERIADOS`

Para actualizar el panel:

1. Registra o modifica la información en esas hojas.
2. No cambies los nombres de las hojas ni los encabezados de la primera fila.
3. Guarda los cambios.
4. Regresa al panel y presiona **Actualizar información**.

El panel también vuelve a consultar la información automáticamente cada cinco minutos.

## 5. Exportar resultados

1. Aplica los filtros que necesites.
2. Presiona **Exportar detalle**.
3. Se descargará un archivo Excel con los registros visibles.

## 6. Consideraciones

- Mantén conexión a internet al abrir la página.
- La fuente debe permitir lectura mediante enlace.
- Si la lectura automática no está disponible, utiliza **Seleccionar respaldo Excel**.
- El logo utilizado está en `assets/ana-logo.png`.
